# Changelog

## 0.1.1 — 2026-09-06

- Added `ppr demo`, which runs the bundled monitor-policy sample from a temporary directory.
- Added the one-click isolated browser demo, offline sample cache, reset controls, and real-data separation.

- Mock DNS, trusted forwarded-chain handling, decision explanations, JSON output, and filtering.
